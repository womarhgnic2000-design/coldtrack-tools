# ColdTrack · Centro de herramientas

Sitio estático con autenticación, base compartida y archivos privados en Supabase. Abrí index.html desde GitHub Pages. Los datos operativos se cargan desde Centro de datos. Cada miembro debe verificar su correo y estar autorizado por el administrador.

El código público no incluye inventarios ni registros de trabajo. La configuración contiene únicamente la URL y clave publicable de Supabase; los permisos se aplican en el servidor.

La creación del proyecto se cotizó en $0/mes. El consumo y los límites dependen del plan de Supabase de la organización.
